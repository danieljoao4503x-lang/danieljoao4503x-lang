## Bot Assistente de Finanças
Um assistente automatizado (via Telegram ou Discord) desenvolvido em **Python** para ajudar no controle de gastos diários. 
**Funcionalidades:** Categorização de despesas, alertas de limites de orçamento e geração de relatórios mensais simplificados salvos diretamente em um Banco de Dados.

## Sistema de Verificação de CPF Avançado
Uma aplicação de validação rigorosa para dados cadastrais.
**Funcionalidades:** Emprega o algoritmo matemático de Módulo 11 para garantir 100% de precisão na validação dos dígitos verificadores. O sistema também filtra padrões de fraude conhecidos (ex: `111.111.111-11`), limpa formatações irregulares e garante que a entrada de dados no banco seja limpa e segura.
